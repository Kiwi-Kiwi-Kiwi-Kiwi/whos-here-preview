# Transcript attribution

The episode file `episodes/s01e01.json` is a processed excerpt of one public transcript.

- **Text:** Avatar Wiki transcript of "The Boy in the Iceberg". Wiki text on Fandom is licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) unless a page says otherwise. Page: https://avatar.fandom.com/wiki/Transcript:The_Boy_in_the_Iceberg
- **Compilation:** Avery Robbins, [appa](https://github.com/averyrobbins1/appa) R package, MIT License.
- **Distribution this file was built from:** TidyTuesday, week of 2020-08-11, `avatar.csv`. The TidyTuesday repository is CC0. That covers TidyTuesday's redistribution, not the wiki text underneath. https://github.com/rfordatascience/tidytuesday/tree/master/data/2020/2020-08-11

This excerpt is shared under **CC BY-SA 3.0**. It contains Season 1 Episode 1 only. It has no timestamps.

`episodes/s01e01.approximate.json` is a separate, hand-timed guide. Its clock times are rounded from a public timed transcript at https://avatard.org/atla_b1/e1/ and were not measured on Netflix. Scene labels in that file are original short descriptions. Every segment is marked approximate.

Character one-line descriptions in `characters.json` are original to this project.
